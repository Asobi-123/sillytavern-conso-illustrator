# 悬浮面板手动测试清单

本清单针对悬浮面板 UI，以及后续挂在悬浮面板里的工具 overlay。

## 前置条件

- 已执行 `npm run build`
- 扩展已加载到可运行的 SillyTavern 环境
- 至少打开一个聊天
- 生图功能本身可用

## 1. 面板外壳

- 打开悬浮面板
  - 预期：面板正常出现，无明显报错
- 关闭悬浮面板
  - 预期：面板隐藏，保留重新打开入口
- 再次打开悬浮面板
  - 预期：面板可正常恢复
- 刷新页面后检查开关状态
  - 预期：面板开关状态能保持

## 2. 主题切换

- 在主控台切换多套主题
  - 预期：面板颜色立即切换
- 分别测试一套深色和一套浅色
  - 预期：文字、输入框、overlay、子卡片都可读
- 打开 `上下文注入设置`
  - 预期：overlay 配色也会跟随主题
- 打开 `世界书管理`
  - 预期：世界书卡片和条目行也会跟随主题

## 3. 主控台

- 切换 `启用自动插画`
  - 预期：底层设置同步变化，并在刷新后保持
- 在主控台切换提示词生成模式
  - 预期：提示词设置页显示对应模式内容
- 修改当前聊天图片文件夹标签
  - 预期：当前聊天标签更新并在聊天切换后正确刷新

## 4. 提示词设置

### 共享 API 模式

- 切到共享 API 模式
  - 预期：只显示 `共享 API 模式` 区域
  - 预期：`独立 API 模式` 区域隐藏
- 切换元提示预设
  - 预期：预览同步变化
- 进入预设编辑
  - 预期：编辑器正常出现，保存按钮状态正常

### 独立 API 模式

- 切到独立 API 模式
  - 预期：只显示 `独立 API 模式` 区域
- 修改基础参数
  - 预期：数值同步更新并能持久化
- 切换 `上下文注入`
  - 预期：底层上下文相关 checkbox 同步
- 切换 `世界书注入`
  - 预期：底层世界书注入 checkbox 同步
- 折叠/展开 `指南预设`
  - 预期：独立工作，不影响其他块
- 折叠/展开 `独立 LLM API`
  - 预期：独立工作，不影响其他块

### 两种模式共用

- 打开 `Tag 超市`
  - 预期：以独立 overlay 打开，不挤在提示词设置内容流里
  - 预期：能看到 catalog 总数、内置/自定义数量和分类统计
  - 预期：搜索、分类筛选、来源筛选、分页和每页数量正常工作
  - 预期：列表区域可滚动，不会被大量 tag 撑爆面板
  - 预期：所有操作按钮横向显示；窄屏可换行，但文字不能竖排
- 测试 `Tag 超市` 自定义 tag
  - 预期：可按原有分类批量加入自定义 tag
  - 预期：重复 tag 自动跳过，不会生成两条同名项
  - 预期：可用“自定义”筛选找出自定义 tag
  - 预期：自定义 tag 可从全部 tag 列表单个删除，也可通过已选择篮子批量删除
  - 预期：已选择 tag 只作为复制 / 加入通用标签 / 删除自定义的临时篮子，不会自动进入 AI 候选
- 测试 `Tag 超市` 中文触发词
  - 预期：可用“无中文触发词”筛选查看缺口
  - 预期：可从 tag 卡片直接打开触发词编辑入口
  - 预期：保存用户触发词后，卡片能看到当前触发词
  - 预期：用户触发词只追加到本地设置，不覆盖内置桥接
- 测试 `Tag 超市` AI 候选透明度
  - 预期：AI 候选数量按分类可编辑，保存后刷新仍保持
  - 预期：说明文字解释候选来源、随机抽样和不发送全库
  - 预期：触发一次独立 prompt 生成后，最近一次候选显示完整来源文本和实际发送 tag
- 打开 `预设适配`
  - 预期：以独立 overlay 打开，不挤在提示词设置内容流里
  - 预期：可选择 JSON / 文本文件自动填入，也可手动粘贴
  - 预期：可切换保存目标：共享 API、独立 API、两者都生成
  - 预期：分析可用文本时不会因长文本被过早截断
  - 预期：生成草稿后需人工保存，不会直接覆盖当前预设
  - 预期：切换目标不会把内置预设错误写入草稿区
  - 预期：共享 API 草稿保留 Conso HTML comment 格式和频率规则；独立 API 草稿只生成独立指南需要的内容
- 打开 `角色固定 Tag`
  - 预期：overlay 打开，编辑器可用
  - 预期：注入方式可切换并持久化
  - 预期：旧方式前置注入仍保持可用
  - 预期：结构感知模式能处理可识别角色段
  - 预期：多人安全模式遇到无法匹配角色段的扁平多人 prompt 时跳过注入，不覆盖错误角色
- 编辑 `提示词检测与风格`
  - 预期：输入、重置等原有逻辑仍可用

## 5. 独立生图

- 打开 `独立生图` 页面
  - 预期：standalone 内容嵌入面板中
- 切换 `上下文注入`
  - 预期：只影响 standalone 的 include-character-info
- 切换 `世界书注入`
  - 预期：只影响 standalone 的 include-world-info
- 在 AI 模式下生成提示词
  - 预期：出现 prompt 卡片
- 使用长文本 `全屏` 按钮编辑 prompt
  - 预期：全屏编辑器打开，应用后写回原卡片
- 在手动 Prompt 模式下使用 `全屏`
  - 预期：全屏编辑器打开，应用后写回手动输入框
- 从 prompt 卡片生成图片
  - 预期：卡片里显示预览

## 6. 世界书管理

- 打开 `世界书管理`
  - 预期：overlay 正常出现
- 搜索世界书
  - 预期：列表过滤正常
- 折叠/展开某本世界书
  - 预期：条目列表按书名正常切换
- 启用/禁用单个条目
  - 预期：当前聊天的配置被更新并保留

## 7. 画廊

- 打开 `画廊` 页面
  - 预期：现有 gallery widget 被嵌入面板，而不是继续独立漂浮
- 展开/折叠消息分组
  - 预期：行为正常
- 从画廊打开图片查看器
  - 预期：原有图片查看器功能正常

## 8. 全屏文本编辑器

- 打开 `元提示` 的全屏编辑/预览
  - 预期：overlay 打开
- 打开 `频率指南` 的全屏编辑/预览
  - 预期：overlay 打开
- 打开 `提示词编写指南` 的全屏编辑/预览
  - 预期：overlay 打开
- 打开 `独立生图 prompt` 的全屏编辑
  - 预期：overlay 打开
- 打开 `预设适配` 导入文本、需求文本和草稿文本的全屏编辑
  - 预期：overlay 打开，文本区自动占满可用高度，不需要手动拖拽才能阅读
- 对可编辑目标点击 `应用`
  - 预期：原字段更新
- 对只读预览目标打开全屏
  - 预期：只读显示，隐藏应用按钮
- 检查全屏弹窗底部按钮
  - 预期：按钮横向排列；窄屏允许换行，但文字不能竖排

## 9. 回归检查

- 点击聊天里的 AI 生成图片
  - 预期：原有的图片操作弹窗仍然出现
  - 预期：悬浮面板不会接管或替换这条逻辑
- 切换聊天
  - 预期：面板仍稳定
  - 预期：当前聊天的世界书和文件夹标签随聊天刷新
- 在聊天流式生成时测试
  - 预期：原有进度提示和流式预览系统仍正常
- 在浅色和深色面板主题下分别打开所有 overlay
  - 预期：不使用酒馆主题色导致输入框或弹窗不可读
