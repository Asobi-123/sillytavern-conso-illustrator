# 悬浮面板手动测试清单

本清单针对悬浮面板 UI，以及后续挂在悬浮面板里的工具 overlay。

## 前置条件

- 已执行 `npm run build`
- 扩展已加载到可运行的 SillyTavern 环境
- 至少打开一个聊天
- 生图功能本身可用

## 1. 面板外壳

- 打开悬浮面板
  - 预期：面板正常出现，无明显报错
- 关闭悬浮面板
  - 预期：面板隐藏，保留重新打开入口
- 再次打开悬浮面板
  - 预期：面板可正常恢复
- 刷新页面后检查开关状态
  - 预期：面板开关状态能保持

## 2. 主题切换

- 在主控台切换多套主题
  - 预期：面板颜色立即切换
- 分别测试一套深色和一套浅色
  - 预期：文字、输入框、overlay、子卡片都可读
- 打开 `上下文注入设置`
  - 预期：overlay 配色也会跟随主题
- 打开 `世界书管理`
  - 预期：世界书卡片和条目行也会跟随主题

## 3. 主控台

- 检查顶部 tab 顺序
  - 预期：顺序为 `主控台` → `提示词设置` → `Vibe 管理` → `画廊` → `独立生图` → `提示词仓库`
- 检查主控台卡片顺序
  - 预期：顺序为 `启动插画` → `提示词生成模式` → `当前聊天` → `正则` → `随机抽取` → `Vibe` → `面板主题` → `信息`
- 切换 `启用自动插画`
  - 预期：底层设置同步变化，并在刷新后保持
- 在主控台切换提示词生成模式
  - 预期：提示词设置页显示对应模式内容
- 修改当前聊天图片文件夹标签
  - 预期：当前聊天标签更新并在聊天切换后正确刷新
- 展开 `正则`
  - 预期：三条内置规则默认全开，分别对应 `img-prompt`、`auto-illustrator`、`img 标签`
  - 预期：全局开关和单项开关能同步到酒馆 Regex 设置，并在刷新后保持
  - 预期：点击 `同步到酒馆 Regex` 会刷新内置模板字段，保留当前启用状态
  - 预期：同步后的规则使用 prompt-only，深度为 `0`，不会删除聊天正文里的元数据

## 4. 提示词设置

### 共享 API 模式

- 切到共享 API 模式
  - 预期：只显示 `共享 API 模式` 区域
  - 预期：`独立 API 模式` 区域隐藏
- 切换元提示预设
  - 预期：预览同步变化
- 进入预设编辑
  - 预期：编辑器正常出现，保存按钮状态正常

### 独立 API 模式

- 切到独立 API 模式
  - 预期：只显示 `独立 API 模式` 区域
- 修改基础参数
  - 预期：数值同步更新并能持久化
- 切换 `上下文注入`
  - 预期：底层上下文相关 checkbox 同步
- 切换 `世界书注入`
  - 预期：底层世界书注入 checkbox 同步
- 折叠/展开 `指南预设`
  - 预期：独立工作，不影响其他块
- 折叠/展开 `独立 LLM API`
  - 预期：独立工作，不影响其他块

### 两种模式共用

- 打开 `Tag 超市`
  - 预期：以独立 overlay 打开，不挤在提示词设置内容流里
  - 预期：能看到 catalog 总数、内置/自定义数量和分类统计
  - 预期：搜索、分类筛选、来源筛选、分页和每页数量正常工作
  - 预期：移动端搜索、分类筛选、来源筛选保持一行紧凑显示
  - 预期：AI 候选数量、最近一次 AI 候选、中文桥接、自定义 tag 收在一个外层辅助面板里
  - 预期：外层辅助面板和内层四个折叠有可辨识的视觉层级
  - 预期：列表区域可滚动，不会被大量 tag 撑爆面板
  - 预期：所有操作按钮横向显示；窄屏可换行，但文字不能竖排
- 测试 `Tag 超市` 自定义 tag
  - 预期：可按原有分类批量加入自定义 tag
  - 预期：重复 tag 自动跳过，不会生成两条同名项
  - 预期：可用“自定义”筛选找出自定义 tag
  - 预期：自定义 tag 可从全部 tag 列表单个删除，也可通过已选择篮子批量删除
  - 预期：已选择 tag 只作为复制 / 加入通用标签 / 删除自定义的临时篮子，不会自动进入 AI 候选
- 测试 `Tag 超市` 中文触发词
  - 预期：可用“无中文触发词”筛选查看缺口
  - 预期：可从 tag 卡片直接打开触发词编辑入口
  - 预期：保存用户触发词后，卡片能看到当前触发词
  - 预期：用户触发词只追加到本地设置，不覆盖内置桥接
- 测试 `Tag 超市` AI 候选透明度
  - 预期：AI 候选数量按分类可编辑，保存后刷新仍保持
  - 预期：说明文字解释候选来源、随机抽样和不发送全库
  - 预期：触发一次独立 prompt 生成后，最近一次候选显示完整来源文本和实际发送 tag
- 打开 `预设适配`
  - 预期：以独立 overlay 打开，不挤在提示词设置内容流里
  - 预期：可选择 JSON / 文本文件自动填入，也可手动粘贴
  - 预期：可切换保存目标：共享 API、独立 API、两者都生成
  - 预期：分析可用文本时不会因长文本被过早截断
  - 预期：生成草稿后需人工保存，不会直接覆盖当前预设
  - 预期：切换目标不会把内置预设错误写入草稿区
  - 预期：共享 API 草稿保留 Conso HTML comment 格式和频率规则；独立 API 草稿只生成独立指南需要的内容
- 打开 `角色固定 Tag`
  - 预期：overlay 打开，编辑器可用
  - 预期：注入方式可切换并持久化
  - 预期：旧方式前置注入仍保持可用
  - 预期：结构感知模式能处理可识别角色段
  - 预期：多人安全模式遇到无法匹配角色段的扁平多人 prompt 时跳过注入，不覆盖错误角色
- 编辑 `提示词检测与风格`
  - 预期：输入、重置等原有逻辑仍可用

## 5. 独立生图

- 打开 `独立生图` 页面
  - 预期：standalone 内容嵌入面板中
- 切换 `上下文注入`
  - 预期：只影响 standalone 的 include-character-info
- 切换 `世界书注入`
  - 预期：只影响 standalone 的 include-world-info
- 在 AI 模式下生成提示词
  - 预期：出现 prompt 卡片
- 使用长文本 `全屏` 按钮编辑 prompt
  - 预期：全屏编辑器打开，应用后写回原卡片
- 在手动 Prompt 模式下使用 `全屏`
  - 预期：全屏编辑器打开，应用后写回手动输入框
- 从 prompt 卡片生成图片
  - 预期：卡片里显示预览

## 6. Vibe 管理

- 打开 `Vibe 管理` tab
  - 预期：Vibe 库、搜索、上传、导入 bundle、导出 bundle、组合保存控件正常显示
- 从主控台 `Vibe Transfer` 卡片点击 `打开 Vibe 管理`
  - 预期：面板切换到 `Vibe 管理` tab
- 上传一张参考图
  - 预期：Vibe 库新增源图项目，自动切到风格组选择里的 `待编码` 组，能看到预览、名称、标签、启用开关和编码状态；新源图默认不启用
- 导入 `.naiv4vibebundle.json`
  - 预期：新增编码 bundle 项目，不覆盖已有项目；没有源图也能显示为可用项目
- 搜索 Vibe 名称和标签
  - 预期：列表正常过滤，空结果显示提示
- 切换 `显示模式` / `编辑模式`
  - 预期：显示模式只读展示单个 Vibe 的强度、信息量和缓存状态；编辑模式显示单个 Vibe 的参数控件
  - 预期：只有编码、没有源图的项目不允许编辑信息提取量
- 混合启用一个源图 Vibe 和一个编码 bundle Vibe 后生成图片
  - 预期：生成流程走 NovelAI 高级后端路由，源图和编码项目都参与
- 保存 Vibe 组合
  - 预期：`另存为` 总是创建新组合，不覆盖已有组合
  - 预期：`覆盖组合` 需要先选中组合并确认目标名称
- 导出 bundle
  - 预期：导出的 `.naiv4vibebundle.json` 只包含有编码的 Vibe；源图、预览图和本地标签不会写入导出文件
- 使用窄屏布局检查 Vibe 管理
  - 预期：卡片单列显示，按钮可换行但文字不竖排，滑条为完整行，列表在面板内滚动

## 7. 生图 SD Style 和 Vibe 组合

- 在主控台展开 `生图 SD Style 和 Vibe 组合`
  - 预期：可以选择关闭、固定、随机模式
- 选择 `固定`
  - 预期：可以选择一个 SD Style 和一个 Vibe 组合
- 生一张聊天图片和一张独立生图
  - 预期：实际使用固定选择，图片画廊/查看器显示本次使用的 SD Style / Vibe 组合名称
- 选择 `随机`
  - 预期：SD Style 抽签池和 Vibe 组合抽签池可折叠、可搜索、可勾选
- 勾选部分池子后连续生几张图
  - 预期：只会从勾选项目里抽取；全不勾时表示全部参与抽签
- 保存一个 SD Style + Vibe 组合搭配
  - 预期：另存为不会覆盖同名旧搭配，会生成唯一名称
